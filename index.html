Administrator Deployment Guide

Follow these steps to connect GitHub Pages with Cloudflare Workers and Zoho WorkDrive.

Worker API URL:

Setting up Zoho Developer Console & WorkDrive

  1. Go to Zoho API Console and click Add Client.
  2. Choose Server-based Applications as the Client Type.
  3. Enter details:
    • Client Name: ResponseRecorder Proxy
    • Homepage URL: Your GitHub Pages URL (e.g. https://username.github.io/repo)
    • Authorized Redirect URIs: https://oauth.pstmn.io/v1/callback or https://example.com/callback
  4. Copy your generated Client ID and Client Secret.
  5. Generate a Grant Token / Refresh Token with scope WorkDrive.workspace.ALL,WorkDrive.files.ALL.
  6. Get your target WorkDrive **Folder ID** from the WorkDrive URL when navigating to your target folder: workdrive.zoho.com/home/folders/[FOLDER_ID].

Deploying the Cloudflare Worker Proxy

Create a new Cloudflare Worker to act as a CORS proxy and handle Zoho OAuth authentication securely without exposing secrets.

worker.js 
export default {
  async fetch(request, env) {
    // Handle CORS preflight
    if (request.method === "OPTIONS") {
      return new Response(null, {
        headers: {
          "Access-Control-Allow-Origin": "*",
          "Access-Control-Allow-Methods": "POST, OPTIONS",
          "Access-Control-Allow-Headers": "Content-Type",
        },
      });
    }

    if (request.method !== "POST") {
      return new Response("Method not allowed", { status: 405 });
    }

    try {
      // 1. Obtain Fresh Access Token using Refresh Token
      const tokenParams = new URLSearchParams({
        refresh_token: env.ZOHO_REFRESH_TOKEN,
        client_id: env.ZOHO_CLIENT_ID,
        client_secret: env.ZOHO_CLIENT_SECRET,
        grant_type: "refresh_token"
      });

      const tokenRes = await fetch(`https://accounts.zoho.com/oauth/v2/token?${tokenParams}`, { method: "POST" });
      const tokenData = await tokenRes.json();

      if (!tokenData.access_token) {
        return new Response(JSON.stringify({ error: "OAuth Token Refresh Failed", details: tokenData }), {
          status: 400,
          headers: { "Access-Control-Allow-Origin": "*", "Content-Type": "application/json" }
        });
      }

      // 2. Relay MultiPart Upload to Zoho WorkDrive
      const formData = await request.formData();
      const file = formData.get("file");
      const filename = formData.get("filename") || "recording.webm";

      const uploadBody = new FormData();
      uploadBody.append("content", file, filename);
      uploadBody.append("parent_id", env.ZOHO_FOLDER_ID);

      const uploadRes = await fetch("https://upload.zoho.com/workdrive-api/v1/stream/upload", {
        method: "POST",
        headers: {
          "Authorization": `Zoho-oauthtoken ${tokenData.access_token}`
        },
        body: uploadBody
      });

      const uploadResult = await uploadRes.json();

      return new Response(JSON.stringify(uploadResult), {
        status: 200,
        headers: {
          "Access-Control-Allow-Origin": "*",
          "Content-Type": "application/json"
        }
      });
    } catch (err) {
      return new Response(JSON.stringify({ error: err.message }), {
        status: 500,
        headers: { "Access-Control-Allow-Origin": "*", "Content-Type": "application/json" }
      });
    }
  }
};

Set Environment Secrets in Cloudflare Worker Settings:

  • ZOHO_CLIENT_ID
  • ZOHO_CLIENT_SECRET
  • ZOHO_REFRESH_TOKEN
  • ZOHO_FOLDER_ID

GitHub Pages Deployment Steps

  1. Create a public or private GitHub repository.
  2. Commit this index.html file to the root directory.
  3. In GitHub, go to Settings -> Pages.
  4. Under Source, select Deploy from a branch, choose main branch and folder / (root).
  5. Click Save. Your portal will be available at https://yourusername.github.io/repository-name/.
